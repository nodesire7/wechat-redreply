# 可选 RedLang 延时撤回接入

已有 OneBot11 插件可以继续使用 `输出流` 和 `撤回`。以下辅助命令使用适配器的 `schedule_delete_msg` 扩展：计划从微信实际发送后计算，支持发送任务尚在队列中时登记。

将 `微信延时撤回.redlang` 的定义放入自己的微信插件初始化脚本，再按需调用：

```text
【微信延时撤回@【输出流@这条提示稍后撤回】@30000】
```

第一个参数必须是该次 `输出流` 返回的消息ID，第二个参数单位毫秒，默认30000。多个独立输出需分别登记，不要把来源消息ID当成输出回执。图片和文字属于同一次输出时，共用回执并一起处理。

这段定义只适用于连接本工具的微信 OneBot11 机器人。多个平台共用插件时，应保留其他平台原有的延时与撤回分支，仅在微信机器人分支调用该命令。需要取消整次输出时，正常使用 `【撤回@输出回执ID】`。

合并转发使用 `send_private_forward_msg` 或 `send_group_forward_msg`，`messages` 支持 OneBot 节点数组。QQ音乐输出使用完整 music/custom 或 QQ音乐 JSON 元数据。封面使用标准 image 段，正文使用 text 段，适配器自动拆成独立微信消息。
